# 美国时间桌面挂件 / US Time Desktop Widget

一个常驻 Windows 桌面的极简挂件：**美国官方时间 + 日期 + 最近 3 个跨境电商节点倒计时**。

纯 PowerShell + WPF 实现，免安装、无第三方依赖、不联网、不写注册表。

![预览](preview.png)

---

## 特性

- **只显示必要信息**：深色半透明圆角卡片，无边框、始终置顶、可拖动、位置自动记忆
- **美国官方时间**：华盛顿特区（东部时间 ET），自动跟随夏令时（EST / EDT）
- **跨境电商节日倒计时**：自动算出最近 3 个营销节点（黑五、网一、圣诞、双11…），≤7 天橙色、≤1 天红色
- **Shift + Space** 一键显示 / 隐藏，另配托盘图标兜底
- **右键菜单**：24 小时制、始终置顶、不透明度、回到右上角、退出
- **单实例**：重复启动不会开出多个，隐藏时双击启动器可唤回

## 快速开始

1. 下载本仓库（`Code` → `Download ZIP`），解压到任意目录
2. 双击 `安装.bat`
   - 若弹出「无法验证发布者」安全提示，点「运行」即可（Windows 对下载来的脚本的默认保护，只会出现一次）
   - 想完全避免：解压前右键 ZIP → 属性 → 勾选「解除锁定」
3. 桌面会生成「美国时间挂件」图标，之后双击该图标启动（不会再弹任何警告）

## 使用

| 操作 | 效果 |
| --- | --- |
| `Shift + Space` | 显示 / 隐藏 |
| 双击卡片 | 隐藏 |
| 单击托盘图标 | 显示 / 隐藏 |
| 左键拖动 | 移动位置（自动记住） |
| 右键卡片 | 24 小时制 / 始终置顶 / 不透明度 / 回到右上角 / 退出 |

**开机自启**：右键 `设置开机自启.ps1` → 使用 PowerShell 运行。
取消：`powershell -ExecutionPolicy Bypass -File .\设置开机自启.ps1 -Remove`

## 节日规则

采用**跨境电商营销日历**（不是美国传统节日表）。浮动日期全部按规则计算：

| 节点 | 规则 |
| --- | --- |
| 元旦、情人节、独立日、返校季(8/15)、万圣节、双11、圣诞、节礼日 | 固定日期 |
| 复活节 | 西方复活节算法（春分后首个满月后的周日） |
| 母亲节 / 父亲节 | 5 月第 2 个周日 / 6 月第 3 个周日 |
| 纪念日 / 劳动节 | 5 月最后一个周一 / 9 月第 1 个周一 |
| 黑五 / 网一 | 感恩节次日 / 感恩节后第 4 天（感恩节 = 11 月第 4 个周四） |

说明：
- 感恩节本身不进列表（它是黑五的锚点，不是购物节点）
- 亚马逊 Prime Day 每年日期不固定，为避免给错日期未收录
- 日期按美国东部时间计算，与挂件显示的日期一致

## 文件结构

| 文件 | 作用 |
| --- | --- |
| `USClockWidget.ps1` | 主程序：WPF 界面、时区换算、节日计算、热键 |
| `launch.ps1` | 启动器：拉起主程序并校验窗口是否真的出现，失败弹框报错 |
| `install.ps1` / `安装.bat` | 一键安装：解除文件锁定、创建桌面快捷方式、启动 |
| `stop-widget.ps1` | 关闭挂件（按窗口定位进程，不依赖 WMI） |
| `重启挂件.bat` | 先关旧实例再启动 |
| `设置开机自启.ps1` | 添加 / 移除开机自启 |
| `widget.ico` | 图标 |
| `使用说明.txt` | 面向最终用户的说明 |

运行时会在程序目录生成 `settings.json`，记录窗口位置与偏好设置（已在 `.gitignore` 中忽略）。

## 实现要点

- **界面**：XAML 描述布局，PowerShell 加载后由 `DispatcherTimer` 每 250ms 刷新
- **时区**：`TimeZoneInfo.FindSystemTimeZoneById('Eastern Standard Time')`，夏令时由系统时区库自动处理
- **热键**：`RegisterHotKey` 注册到隐藏消息窗口（C# P/Invoke），收到 `WM_HOTKEY` 后切换窗口可见性；被其他程序占用时自动回退到备用组合
- **节日**：固定日期 + 规则函数（复活节用 Meeus/Jones/Butcher 算法，其余按「第 n 个周几 / 最后一个周几」计算），排序后取最近 3 个
- **单实例**：按窗口标题检测已有实例，卡死的残留进程不会阻塞新实例启动

## 常见问题

**双击后没反应？**
首次启动需要 3~5 秒（编译界面代码），窗口出现在屏幕右上角；也可以看托盘区是否多出时钟图标。

**Shift+Space 没反应？**
1. 先确认挂件在运行（托盘有图标）
2. 若该组合被其他软件占用，挂件会自动改用 `Ctrl+Shift+Space` / `Alt+Shift+Space`，并在卡片上提示
3. 系统里若有卡死的旧进程占着该热键，结束它或重启一次

**文件夹挪位置后图标打不开？**
重新运行一次 `安装.bat`。
