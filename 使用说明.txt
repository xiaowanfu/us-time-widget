美国时间桌面挂件 · 使用说明
==================================

【是什么】
桌面上一个小卡片，显示：
  · 美国官方时间（华盛顿特区 / 东部时间，自动跟随夏令时）
  · 日期
  · 最近 3 个跨境电商节点的倒计时（黑五、网一、圣诞…）

【怎么装】
1. 把整个文件夹解压到任意位置（例如 D:\挂件）
2. 双击 安装.bat
   → 如果弹出“无法验证发布者”的安全警告，点【运行】就行（只会弹这一次）
3. 桌面会生成「美国时间挂件」图标，以后都双击这个图标启动，不会再弹警告

小技巧：解压前先右键压缩包 → 属性 → 勾选“解除锁定” → 确定，再解压，
就能完全避开那个安全警告（那是 Windows 对下载来的脚本文件的默认保护）。

【怎么用】
Shift + Space     显示 / 隐藏
双击卡片          隐藏
单击托盘小图标    显示 / 隐藏
左键拖动          移动位置（位置会记住）
右键卡片          24 小时制 / 始终置顶 / 不透明度 / 隐藏 / 回到右上角 / 退出

【开机自启】
右键 设置开机自启.ps1 → 使用 PowerShell 运行
取消：powershell -ExecutionPolicy Bypass -File .\设置开机自启.ps1 -Remove

【常见问题】

Q: 双击后没反应？
A: 首次启动要 3~5 秒（要编译界面），窗口出现在屏幕右上角；
   也可以看右下角托盘区有没有多出一个时钟小图标。

Q: Shift+Space 没反应？
A: 按顺序排查：
   1) 看托盘有没有时钟图标 —— 没有就是没启动，双击桌面图标
   2) 如果图标在、按键没反应，多半是系统里有一个**卡死的旧进程**占着这个快捷键。
      打开任务管理器 → 详细信息，找 "powershell.exe"，
      把不是当前挂件的都结束掉；最省事的办法是重启一次电脑。
      本版已修复“退出不干净、残留进程”的问题，正常使用不会再出现。
   3) 如果 Shift+Space 被别的软件占用，挂件会自动改用
      Ctrl+Shift+Space / Alt+Shift+Space，并在卡片上提示。

Q: 文件夹挪位置后图标打不开了？
A: 重新运行一次 安装.bat，会重新指向新位置。

Q: 怎么卸载？
A: 右键卡片 → 退出挂件，然后删掉文件夹和桌面上的图标即可。
   如果开了开机自启，先运行一次 设置开机自启.ps1 -Remove。

【技术说明】
- 纯 PowerShell + WPF，不联网、不装服务、不写注册表
- 只在程序目录生成一个 settings.json，记录窗口位置和偏好设置
- 支持 Windows 10 / 11（系统自带的 PowerShell 5.1 即可）
